# انتقال AliUPFit به Laravel

این پروژه نسخهٔ Laravel صفحهٔ فعلی AliUPFit است. فایل `resources/views/site.blade.php` از HTML ارسالی ساخته شده و ساختار و CSS صفحهٔ عمومی، نام کلاس‌ها، فونت‌ها، تصاویر جاسازی‌شده، متن‌ها و رفتار responsive آن دست‌نخورده نگه داشته شده است. تنها تغییرهای public در نقاط اتصال backend است: مقدار تنظیمات از پایگاه‌داده خوانده می‌شود و ارسال معتبر فرم قبل از نمایش پیام موفقیت در پایگاه‌داده ثبت می‌شود. ظاهر پنل مدیریت مستقل است و CSS صفحهٔ اصلی را تغییر نمی‌دهد.

## نیازمندی‌ها

PHP 8.3 یا جدیدتر، Composer، افزونه‌های `pdo_sqlite`, `mbstring`, `xml`, `curl` و `zip` لازم است. برای سرور تولیدی می‌توان تنظیم اتصال را از SQLite به MySQL/MariaDB با `.env` استاندارد Laravel تغییر داد. رمزها و `APP_KEY` را در فایل `.env` محیط خود نگه دارید و هرگز آن فایل را عمومی نکنید.

## نصب و اجرا

```bash
cp .env.example .env
composer install
php artisan key:generate
mkdir -p database
touch database/database.sqlite
php artisan migrate --seed
php artisan serve --host=127.0.0.1 --port=8000
```

سپس سایت در `http://127.0.0.1:8000` و صفحهٔ ورود مدیر در `http://127.0.0.1:8000/admin/login` در دسترس است. اگر نصب روی هاست انجام می‌شود، document root وب‌سرور باید به پوشهٔ `public/` پروژه اشاره کند. در محیط تولیدی `APP_ENV=production`, `APP_DEBUG=false`, `APP_URL` و کلید محرمانهٔ تازه تنظیم شوند.

## ساخت حساب مدیر

هیچ کاربر آزمایشی یا رمز پیش‌فرضی در پروژه نیست. پس از اجرای migrationها مدیر را صریحاً در ترمینال سرور بسازید:

```bash
php artisan admin:create admin@example.com
```

دستور نام و رمز را به‌صورت تعاملی می‌پرسد؛ رمز باید حداقل ۱۲ نویسه باشد. ثبت‌نام عمومی مدیر وجود ندارد. حساب‌های غیرمدیر به پنل دسترسی ندارند.

## داده‌های پایدار

فرم‌های ثبت‌نام کلاس، برنامهٔ تمرینی، تغذیه، ارزیابی و تماس پس از اعتبارسنجی سرور در جدول `form_submissions` ذخیره می‌شوند. در پنل مدیر می‌توان دادهٔ واقعیِ ارسال‌شده، زمان ثبت، وضعیت پیگیری، ویرایش وضعیت و حذف درخواست را مدیریت کرد. هیچ درخواست ساختگی داخل seeder تولید نمی‌شود.

در صفحهٔ «تنظیمات سایت» مدیر می‌تواند تلفن، واتساپ، اینستاگرام، نشانی، قیمت‌ها، ظرفیت سانس‌ها و نشانی تصویر مربی را به‌روزرسانی کند. تنظیمات در جدول `site_settings` ذخیره می‌شوند و در نمای عمومی سایت به تنظیمات جاوااسکریپتی اصلی تزریق می‌شوند. فیلدهای خالی تماس و قیمت به‌عنوان مقدار واقعی خالی باقی می‌مانند؛ اطلاعات ساختگی جایگزین نشده‌اند.

## دیتابیس تولیدی

SQLite برای راه‌اندازی محلی پیش‌فرض است. برای MySQL/MariaDB، مقادیر `DB_CONNECTION`, `DB_HOST`, `DB_PORT`, `DB_DATABASE`, `DB_USERNAME`, و `DB_PASSWORD` را در `.env` واقعی سرور تنظیم و سپس اجرا کنید:

```bash
php artisan migrate --force
```

برای حفاظت داده‌ها از دیتابیس و فایل‌های پشتیبان به‌صورت منظم backup بگیرید. درخواست‌های عمومی rate limit شده‌اند و نشست ورود مدیر از session middleware استاندارد Laravel استفاده می‌کند.
